How to read this board

This radar ranks DeFi protocols that have no token on record, by the implied value of a future token launch. Each protocol’s value is modelled as TVL times a category multiple — calibrated from this snapshot’s own live-token protocols, as the median market-cap-to-TVL ratio per category, shrunk toward the global median — times growth, maturity and chain-breadth multipliers, with no hardcoded protocol lists. Every farm plan is derived from that protocol’s own record: its category, chains, TVL and age.

    Method

    Implied value = TVL × category multiple × growth multiplier × maturity multiplier × chain multiplier. The category multiple is the median mcap/TVL of the snapshot’s live-token protocols in the same category, shrunk toward the global median, so a thin category cannot set an extreme multiple on its own. Growth follows the protocol’s 7-day TVL change, maturity rises with the time it has run with no token, and chain breadth rewards protocols live on more chains. The model uses only figures from the sealed snapshot; no protocol is named or hand-picked anywhere in the code. Implied values are estimates, not prices and not a promise of a launch.
